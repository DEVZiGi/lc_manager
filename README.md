# LC Manager

An external Quality of Life (QoL) dashboard and overlay tool for **Lobotomy Corporation**, created by **zigi** (zigisoftware). 

The tool establishes a live data pipeline via memory injection to extract facility state into a unified UI without putting unnecessary performance strain on the game engine.

## Technical Stack

- **Language:** C++17 & C# (SDK Backend)
- **UI Framework:** Dear ImGui
- **Window/Context:** GLFW3
- **JSON Parser:** nlohmann/json
- **Injection Interface:** SharpMonoInjector
